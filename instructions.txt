PHASES & TASKS
--------------
- The Austen file still contains some Gutenberg noise. Cleaning it is part of
  Phase 1.
- The BBC download contains two copies of every article (about 4,450 files for
  2,225 articles). Remove the duplicates before you use it.
- Split the primary corpus (Austen and Shakespeare) into 80% train / 10%
  validation / 10% test before building the vocabulary or training any model.
  Split by whole sentences (or blocks of consecutive sentences), not by
  individual windows. Use a fixed random seed.
- Window size: use k = 20 for Phases 3–6 (Phase 2 varies k).


--------------------------------------------------------------------------------
PHASE 1 – Sequential Data Engineering (15 points)
--------------------------------------------------------------------------------
Goal: Transform raw text into a format suitable for recurrent layers.

- Implement a sliding window tokenizer. Convert text into sequences of k words
  as input with the next word as target (for example, "it is a truth" with
  k = 3 gives input "it is a" and target "truth").
- Build the vocabulary from the training split only. Words below a minimum
  count (state it) become <UNK>. Report the vocabulary size and the <UNK> rate
  on the train, validation and test splits.
- Add <s> and </s> tokens at sentence boundaries.


--------------------------------------------------------------------------------
PHASE 2 – The Vanishing Gradient Experiment (25 points)
--------------------------------------------------------------------------------
Research question: How do Simple RNNs and LSTMs differ in keeping long term
dependencies?

- Train a Simple RNN and an LSTM on the same next word prediction task, with
  the same embedding size, hidden size, optimizer and number of epochs (state
  the values you chose).
- Compare their performance as the window size increases: repeat for
  k = 5, 10, 20, 40 and 80 and plot validation perplexity against k for both
  models. Evaluate all values of k on the same target words, so the
  perplexities are comparable.


--------------------------------------------------------------------------------
PHASE 3 – Hyperparameter & Architecture Research (10 points)
--------------------------------------------------------------------------------
Goal: Find the best architecture through systematic testing.

- You decide the number of layers (1 to 3), hidden units (128, 256, 512) and
  dropout (0, 0.2, 0.5).
- Run at least 9 experiments with early stopping on validation perplexity. At
  least 2 of them must be Simple RNN configurations.
- Model selection: the best RNN and the best LSTM are the ones with the lowest
  validation perplexity. Report test perplexity for every run, but do not use
  it to choose a model. These two models are used in Phases 4, 5 and 6.


--------------------------------------------------------------------------------
PHASE 4 – Next Word Prediction Chatbot (30 points)
--------------------------------------------------------------------------------
Goal: Use your best LSTM model to generate text interactively.

- Build a chatbot from your best LSTM.
- Write an input() loop where the user enters a seed phrase and a number N, and
  the model generates the next N words. Typing quit should end the loop.
  Invalid input must not crash the loop.
- Support greedy decoding (always the most probable word) and temperature
  sampling, and let the user choose.


--------------------------------------------------------------------------------
PHASE 5 – Perplexity and Confidence Analysis (20 points)
--------------------------------------------------------------------------------
Research question: Are some sentences harder for the model than others, and can
we tell from simple features?

- Take the probability your model gives to the correct next word at each
  position and compute the perplexity of every test sentence (a sentence runs
  from <s> to </s>). Do this for your best RNN and best LSTM.
- Split the test sentences into three equal-sized groups (short, medium, long)
  by length and compare RNN and LSTM perplexity in each group.
- Fit a linear regression that predicts sentence log-perplexity from sentence
  length and share of rare words (a word is rare if it occurs fewer than 50
  times in the training split; <UNK> counts as rare). Fit it on 70% of the test
  sentences and report R^2 and RMSE on the remaining 30%.

Perplexity of a sentence with N predicted tokens (count </s> as a predicted
token; <s> is never predicted):

    PP(W) = P(w1, w2, ..., wN) ^ (-1/N)


--------------------------------------------------------------------------------
PHASE 6 – Multi Style NLP Adaptation (40 points)
--------------------------------------------------------------------------------
Goal: Investigate model adaptability across different linguistic distributions.

- Task: Take your model trained on the primary corpus (Austen and Tiny
  Shakespeare) and test its next word prediction on a completely different
  style: the BBC News articles provided above.
- Requirement: Calculate the change in perplexity when the model encounters
  this out of domain text.

Report Expectations: Discuss the "Generalization Gap" and how specialized vs.
generalized training data influences model performance.
